# 评测

两类评测，都不依赖特定 Agent 平台。

## 1. 触发评测（triggers.json）

把每条 prompt 发给装了本技能和其他常用技能的 Agent，记录它有没有选中本技能。

- 应该触发的条目：召回率 ≥ 90%
- 不应触发的条目：误触发率 ≤ 10%

改 `SKILL.md` 的 description 前后各跑一次，对比两次结果。

## 2. 行为评测（scenarios.json）

每个场景跑两次：

- 一次装本技能
- 一次不装

按 `must` 和 `must_not` 逐条判定，可以人工判，也可以交给另一个模型判。

- `must_not` 命中任何一条就算回归，不能发版。
- `must` 的通过率要明显高于不装技能的那一次。否则说明这部分说明没起作用，应该删掉。

## 记录

结果按日期追加到 `evals/results.md`，写清：

- 模型名
- 技能版本
- 两类评测的通过率
- 失败条目
